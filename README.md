# 三国志14 威力加强传承版实时修改器

## 基础属性自动识别修改

1. 进入简体中文传承版的剧本，运行修改器（源码运行 `main.py` 或打开打包后的 `dist/SAN14CE_Full_Trainer.exe`）。顶部显示「已连接」后即可使用，右上角支持「快捷键 / 提示音 / 窗口置顶」开关。
2. 在游戏里打开武将详情、城市情报、区域情报、关隘情报或部队情报。在修改器的「基础修改」里核对对应分组显示的当前数值。
3. 输入新值并点击对应的「写入」，也可返回游戏按该行的快捷键。点击每行左侧的快捷键按钮即可自定义任意组合键（修改后自动保存，也支持一键恢复默认）。
4. 每个编辑分组顶部都配有快捷操作按钮：**读取当前值**、**一键全满**，城市/关隘/部队还支持 **削弱(归1)** 与 **一键净化**（清除混乱/挑衅/止步/伤兵）。
5. 如果游戏详情还显示旧值，关闭并重新打开详情。武将和部队也可以切换「基本」和「能力」页签来刷新。

当前支持自动定位写入的基础项目：
- 全局：无限命令书（持续锁定 99）、最高施政等级（主义经验满级 Lv.10）。
- 武将：统率、武力、智力、政治、魅力、忠诚度、施政等级、突破能力上限（五维上限 120）、出生年份、伤病状态（全部 10 项均已接入自动定位）。
- 城市：耐久、士气、资金、兵粮、士兵、伤兵、挑衅剩余天数、混乱剩余天数、都市规模 1~4（全部 9 项均已接入自动定位）。
- 地区：商业开发、农业开发、兵舍开发、地区人口、地区治安、建设上限（全部 6 项均已接入自动定位）。
- 关隘：耐久、士气、士兵、伤兵、挑衅剩余天数、混乱剩余天数（全部 6 项均已接入自动定位）。
- 部队：士气、士兵、伤兵、挑衅剩余天数、混乱剩余天数、止步剩余天数、携带资金、携带兵粮（全部 8 项均已接入自动定位）。

## 武将进阶编辑（阵型 / 延寿 / 主义 / 政策 / 能力上限）

在顶部分页中切换到「武将进阶」：
- 支持一键读取当前详情武将，或加载剧本中全部武将并按姓名/ID 搜索。
- **阵型解锁（14 项）**：逐项勾选鱼鳞、锋矢、雁行、方圆、鹤翼、长蛇、锥行、井阑、冲车、投石、走舸、蒙冲、楼船、四夷，并提供「全陆战」「全水陆」「含四夷全解锁」一键按钮。
- **生平与状态**：修改出生年份、卒年（一键延寿至 350 年）、忠诚度、伤病状态、主义（王道/霸道/我道/割据/名利/礼教）、自带政策与等级（实时读取游戏政策表）、五维能力上限。

## 势力批量 / 外交异族 / 名品管理

在顶部分页中切换到「势力 / 外交 / 名品」，点击「刷新世界数据」后可使用三大子功能：
- **己方势力批量修改**：命令书/施政满级快捷按钮；己方全都市一键补给（仅修改玩家势力下辖都市）；己方全区域一键满开发与满治安；己方全武将一键满忠诚、治愈伤病、解锁阵型或延寿。
- **外交 / 异民族 / 海外诸国**：调整与各在场势力及五异民族（乌桓/鲜卑/羌/山越/南蛮）的双向友好度（支持一键满友好 100）；调整与海外四国（天竺国/贵霜国/安息国/大秦国）的友好度与通商等级（支持四国一键满友好满通商）。
- **名品归属管理**：按名称/持有者/状态搜索剧本中全部名品，并将其直接授予目标武将（支持一键设为当前游戏内打开的详情武将）。

## 个性（5 槽位）与战法 / 战技（10 槽位）修改

在顶部分页中切换到「战法 / 战技」或「个性」，支持 **剧本实时修改（内存）** 与 **存档文件修改（.s14）** 两种模式，并内置 **方案预设**（野战神将 / 谋略攻城 / 内政神辅，且支持保存与删除自定义方案）。

### 无限制自创个性（突破官方点数 / 效果 / 数值限制，支持进剧本前选用）
在「个性」分页底部点击 **「无限制自创个性...」** 即可打开工坊：
- **进剧本前直接给史实武将 / 自创武将选用**：点击 **「写入全局（进剧本前给史实/自创武将可选）」**，会按 100% 精确格式写入 Steam 存档目录下的 `editpersonalityexceSC.s14`（自动生成 `.bak` 备份）；如果游戏当前正开在主菜单或剧本中，还会同时实时同步游戏内存中的 `CEditPersonalityData[0~99]` 与 `CPersonalityData[256~355]`，**无需重启游戏**即可直接在主菜单的「编辑新武将 / 登录新武将」和「编辑史实武将」中勾选套用，且之后新开任何剧本都会自动带入。
- **剧本内实时注入与一步装备**：也支持直接写入当前运行剧本的 100 个自创个性槽位（`CPersonalityData[256~355]`）并一键装备到当前武将，随游戏原生 `.s14` 存档永久保存。
- **完全无点数限制、无禁用列表**：支持全部 126 种引擎真实效果（含飞将无视 ZOC、无视包围、洞察免疫异常、卧龙、火神、强运、动员、王佐、富豪、神将光环等）任意双效果自由混搭。
- **原版正常值对照 & 突破官方数值上限**：每个效果旁均直接标注游戏原版正常数值及一键「填正常值」按钮；全局文件支持 `-100 ~ +2000`（如全能力 +2000、攻防 +500、动员 +2000），剧本内存直写更支持 `-1000 ~ +30000`（如动员 +20000、富豪 +5000）。
- **无地形/兵种限制 & 自定义光环格数**：触发条件默认为「无条件常驻」，舰船、兵器与全地形皆可生效；也可设为友军/敌军光环并自由指定光环格数。
- 内置 6 套神技模板（战神无双 / 不败金身 / 神速破阵 / 百万大军 / 天命内政 / 霸主光环），并自动保存到本地库 `profiles/custom_traits.json`。

> 提示：所有实时内存修改均自动记录原始字节，可随时点击窗口底部「恢复全部修改」一键撤销；战法库中标注为 `DLC`（ID 170~183）的联动战法建议仅在游戏已启用对应 DLC 时装备。
